# 🪨📄✂️ Rock, Paper, Scissors – Java Console Game

Welcome to a simple yet classic implementation of the **Rock, Paper, Scissors** game in **Java**! This console-based project allows users to play the timeless hand game against the computer.

---

## 🎮 How It Works

The game is played in the terminal. Here's what happens:

1. The user chooses either `Rock`, `Paper`, or `Scissors`.
2. The computer makes a random selection from the same options.
3. The winner is decided based on these standard rules:

   * **Rock beats Scissors**
   * **Scissors beats Paper**
   * **Paper beats Rock**

The result (Win, Lose, or Draw) is then displayed.

---

## 💡 Features

* Simple and interactive terminal-based interface
* Randomized computer moves for fairness
* Input validation to ensure smooth user experience
* Easy-to-read and maintain code (great for beginners!)

---

## 🚀 Getting Started

### Prerequisites

Make sure you have **Java** installed on your system. To check, run:

```bash
java -version
```

If not installed, [download Java](https://www.oracle.com/java/technologies/javase-downloads.html) and install it first.

### Run the Game

1. Clone the repository or download the `.java` file.
2. Open your terminal and navigate to the project directory.
3. Compile the Java file:

```bash
javac RockPaperScissors.java
```

4. Run the game:

```bash
java RockPaperScissors
```
